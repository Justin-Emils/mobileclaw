**本轮新增的关键硬事实（后续开发必须遵守）**：
1. **`ACTION_SEND` 接收方只拿到 URI + 临时读权限，无法把结果写回来源 App**。回程只能"再调起系统 chooser / 写剪贴板 / 保存到目录"。→ 全流程统一表述为「进来：Share；出去：再分享/保存/复制」，**严禁承诺"原地改好回到原 App"**。Android 14+ 才有 ChooserAction，且 AEP 强制系统 chooser、禁止自建分享菜单。
2. **审批 UX 是一等特性**：批量操作＝一次逻辑确认（看 diff），**不是逐文件弹窗**（会训练用户盲点"同意"）。要规划可回看的审批面板（竞品空白点）。
3. **SAF（tier2）是增强路径而非首值前置**：先用过一次 tier1 见到价值才引导授权；若中间层拒绝授权，US1/US3/US4 仍独立成立。
4. **端侧用窄域小模型做意图→动作路由**（AI Edge Gallery 的 270M FunctionGemma，微调后 58%→85%），比跑通用大模型现实。
5. **三个正交产品目标**：G1 零门槛（不进任何系统设置即可完成一次真实文件批处理）/ G2 可信可控（每次动作可见·可拒绝·可回看；数据损失事件＝0）/ G3 可移植（内核与技能记忆跨设备携带）。

**待产品负责人拍板**：tier2（SAF 授权）究竟做「增强路径」还是「阶段 1 前置」——后者会直接改写 M1 关键路径与路线图 3 的排期绑定。
