## 2. 边界与异常场景清单 ⚠（本次重点）

| # | 场景 | 期望处理 |
|---|---|---|
| 1 | 批量 200 个文件的性能/确认负担 | 分批+虚拟列表；同类动作"一次确认"；进度可见可取消 |
| 2 | 重名/冲突 | 检测冲突，默认加序号或跳过，**绝不静默覆盖** |
| 3 | 中文·emoji·空格·超长文件名 | 保 UTF-8、不拆代理对；超长报错而非静默截断 |
| 4 | 部分成功部分失败 | 逐项结果清单：成功保留、失败可重试，汇总通知 |
| 5 | 分享进来非文件（纯文本/图片/链接/混合） | 类型嗅探分流：文本→US4，文件→US1/3，混合→让用户选范围 |
| 6 | 用户中途取消审批 | 立即停止；已执行保持、未执行丢弃，可回滚 |
| 7 | 权限被拒/授权过期(SAF/日历) | 说明"哪步需何权限"+重授权深链，不静默失败 |
| 8 | 无网/模型不可用 | 明确报错；配端侧则本地降级；**不伪造结果** |
| 9 | 大文件 | 读/编辑走流式或设上限，超限说明原因 |
| 10 | 模型返回非法/危险动作(越授权范围) | PathGuard 词法绝对拦截+给理由，**不进审批** |
| 11 | 重复执行/幂等 | 重命名/归档幂等；重复确认无副作用 |
| 12 | 分享出去目标 App 不支持 | 回退通用 Share sheet；提示可复制文本 |

## 4. 主故事 Given/When/Then 要点

**US1** — Given 分享了 N 个文件 When 输重命名指令 Then 先出预览可逐项改｜Given 文件名重复 When 确认 Then 加序号不覆盖｜Given 用户取消 Then 零变更。
**US2** — Given 未用过 tier1 When 想选目录 Then 先引导用 Share（先见价值再要授权）｜Given 已预览 When 系统拒跨树移动 Then 说明并保留部分成功。
**US3** — Given 分享的是纯文本 When 进入 Then 走非文件路径并提示｜Given 归档成功 Then 通知+可撤销。
**US4** — Given 时间歧义 When 预览 Then 高亮所解析日期供改｜Given 无日历权限 Then 引导授权，不静默丢。
**US5** — Given 模型路径越界 When 执行 Then PathGuard 拒绝且不入审批｜Given Shizuku 重启 When 调用 Then 复检状态并提示重授权。
